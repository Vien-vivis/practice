# Учебная практика: Сайт Agency (Astro + Strapi)

Проект корпоративного сайта digital-агентства с блогом.

## Стек
- **Frontend:** Astro.js, Tailwind CSS, TypeScript
- **Backend:** Strapi 5 (Headless CMS)

## Локальный запуск
1. Запустить бэкенд:
   cd backend && npm run develop
2. Запустить фронтенд (в новом терминале):
   cd frontend && npm run dev
